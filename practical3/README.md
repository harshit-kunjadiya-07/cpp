# Vehicle Registry System

C++ project for managing different types of vehicles using Object-Oriented Programming.

## Features

* Add Vehicle
* View All Vehicles
* Search Vehicle by ID
* Exit

## Vehicle Types

* Car
* Electric Car
* Sports Car
* Flying Car
* Sedan
* SUV

## Concepts Used

* Class & Object
* Encapsulation
* Constructors & Destructor
* Static Member
* Getters & Setters
* Array of Objects
* Single Inheritance
* Multilevel Inheritance
* Multiple Inheritance
* Hierarchical Inheritance

## Language

C++
