# Banking System

## Description

A simple C++ Banking System that manages different types of bank accounts.

### Features

* Create Savings Account
* Create Checking Account
* Create Fixed Deposit Account
* Deposit Money
* Withdraw Money
* Calculate Interest
* Check Account Information
* Menu-driven interface

### Concepts Used

* Class and Object
* Inheritance
* Polymorphism
* Encapsulation
* Exception Handling
* Dynamic Memory Allocation

### Language

**C++**
