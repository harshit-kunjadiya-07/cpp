# Library Management System

## Description

A simple C++ Library Management System that manages different types of library items.

### Features

* Add Book
* Add DVD
* Add Magazine
* Display Library Items
* Check Out Item
* Return Item
* Menu-driven interface

### Concepts Used

* Class and Object
* Abstraction
* Inheritance
* Polymorphism
* Encapsulation
* Exception Handling
* Dynamic Memory Allocation

### Language

**C++**
